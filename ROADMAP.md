Ordered by priority. Items 1-4 and 7 are DONE (first real study + the deferred statistics).

## 1. First real-data run -- DONE

Reused the tau-bench **retail** trajectories collected in `Gjusev/gate-calibrated` as the first real study:

- **Done:** [`docs/results/first-study.md`](docs/results/first-study.md), regenerated by the deterministic `scripts/first_study.py` (pure parsing of the real JSONLs, zero LLM calls).
- Headline: glm-5.3-flash, split=all, k=2, 494 tasks: pass^1 = 0.9160, consistently-solved (2/2) = 0.9069 (Wilson 95% CI [0.8780, 0.9295]), unbiased pass@2 = 0.9251.
- Two-version comparison found in the data (not manufactured): the glm-5.3 vs glm-5.3-flash fit-split pilots (12 shared tasks, k=1). Honest deviation: with k=1 the paper's consistency McNemar is not computable; plain per-task McNemar yields zero discordant pairs (uninformative). The five k=4 policy runs carry the real paired comparisons -- all null, underpowered (see study §4).
- pass^1 sanity-checks against the gate-calibrated project's own per-run reward rates.
- README status upgraded from "mechanism implemented" to "benchmarks validated on this dataset".

## 2. Wilcoxon signed-rank companion test -- DONE

`reliagate/stats.py:wilcoxon_signed_rank` on `d_x = c_x_new - c_x_base` with average-rank ties handling, zeros dropped, exact 2^n enumeration for n_nonzero <= 20 and tie-corrected normal approximation (continuity correction) above; one- and two-sided. Every `compare()` result now carries `wilcoxon` (arXiv:2604.17849 §2.2).

## 3. Multiple-comparison correction for task categories -- DONE

`compare(..., task_categories=..., correction=...)`: Holm step-down for confirmatory gates, Benjamini-Hochberg for exploratory dashboards, over the per-category McNemar family; adjusted p-values land in `ComparisonResult.category_tests` / `correction`. (Max-statistic bootstrap calibration for tiny category counts remains open, only relevant below ~5 categories.)

## 4. Hierarchical bootstrap -- DONE

`reliagate/stats.py:hierarchical_bootstrap`: scenarios -> tasks resampled with replacement, per-task run aggregates held FIXED during resample (arXiv:2605.08261 §4.3; rollout-level resampling reached 17% coverage in that paper). Used in the first study with tiers as the scenario level.

## 5. Adapter: Inspect AI (stub)

Read Inspect AI `eval_set` logs with `epochs=N` into EvalRun. Lazy import, optional dependency, tests skipped when inspect-ai is absent. Do NOT stub the metrics -- map their epoch reducers honestly or don't map them.

## 6. Adapter: Langfuse (stub)

Ingest Langfuse experiment scores for repeated runs per dataset item. Same rules as 5.

## 7. Newcombe interval for the paired difference -- DONE

`reliagate/stats.py:newcombe_paired`: hybrid-score interval for the difference of two paired proportions (Wilson marginals combined with the observed within-pair correlation, Newcombe 1998 method 10). Every `compare()` result carries `newcombe`; the CLI prints it next to the McNemar p-value.

## 8. Group-sequential alpha spending

O'Brien-Fleming checkpoints for CI that evaluates per PR (simpler to reason about than SPRT for that cadence). Complements `sprt_stop`.

Item 1 is done; remaining precondition: decide whether the first study's null policy results need a second dataset (e.g. airline) before publishing.
